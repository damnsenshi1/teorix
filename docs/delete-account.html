Delete your TeoriX account

In the app

Open Profile → Cloud Progress → Delete My Account. Confirm the deletion. This permanently removes the cloud account and cloud data linked through database cascade rules. Study data stored only on the current device is not automatically removed.

Türkçe

Profil → Bulut İlerlemesi → Hesabımı Sil yolunu aç ve işlemi onayla. Bulut hesabın ve hesapla ilişkili bulut verileri kalıcı olarak silinir. Yalnızca cihazında saklanan yerel çalışma verileri otomatik silinmez.
